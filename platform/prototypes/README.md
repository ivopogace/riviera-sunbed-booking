# Prototypes

Throwaway demos that answer one design question each. Nothing here is built, tested, linted or
deployed — each is a single self-contained HTML file you open in a browser.

A prototype earns its keep by being *pressed*, not read. The module at the top of each file's
script is the part written to survive: if the question is answered "yes", that shape lifts into the
real module and gets rebuilt test-first through the normal loop. The page around it is disposable.

| File | The question it answers |
|---|---|
| `abandon-unpaid-booking.prototype.html` | Can a guest be given an explicit way to give up an unpaid booking, and what are they told when the payment is already in flight, already through, or the provider is unreachable? |
