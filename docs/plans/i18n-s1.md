# i18n S1 — Angular i18n with Albanian and Italian on the tourist booking path

> Build with `tdd` at the named seams. Invariant numbers: `CLAUDE.md`.

**Goal:** the SPA builds and serves `en` (root), `sq` (`/sq/`) and `it` (`/it/`); a language row
switches between them keeping the route; the first-batch tourist pages render fully in `sq` and `it`.

**Architecture:** Angular's built-in i18n (`i18n` attributes + `$localize`), compiled per locale at
build time (ADR-0030). Spring maps each locale subpath's client routes to that build's `index.html`
through one enum, `SpaLocale`. The choice is device-local (`localStorage`, like the theme), so the
first-visit redirect of `/` runs in the root shell's inline script: stored choice, then
`navigator.languages` (the browser's `Accept-Language` list), then English.

**Source of intent:** issue #1734 (triage `## Decisions` + `## Agent Brief`, the #1735/#1736 residual comments).

**Branch:** `claude/1734-i18n-s1-6219f5` (worktree branch standing in for `feature/i18n-s1`).

## Acceptance criteria

- [ ] **AC-1:** Given the production build, when it runs, then it emits the `en` shell at the root and
  the `sq`/`it` shells under `sq/` and `it/`, each with its own `lang` and `<base href>`, and fails on
  a marked message without a translation. *Seam:* `npm run build` (`i18nMissingTranslation: error`) ·
  *Pinned by:* CI `frontend` build + the locale e2e (`locales.e2e.ts`).
- [ ] **AC-2:** Given the served SPA, when a client asks for `/sq/venues/1`, `/it/booking/X`, `/sq/`
  or `/venues/1`, then it gets that locale's shell; a missing `/sq/*.js` is a 404; `/api/**` never
  falls back. *Seam:* `SpaWebConfig`'s resource chain · *Pinned by:*
  `SpaShellTest.eachLocaleDeepLinkServesThatLocalesShell`, `SpaFallbackResolverTest.aLocaleSubpathResolvesToThatLocalesShell`.
- [ ] **AC-3:** Given `SpaLocale` and `frontend/angular.json`, when the locale lists differ, then the
  build fails. *Seam:* `SpaLocale` · *Pinned by:* `SpaLocaleTest`.
- [ ] **AC-4:** Given the language row on any tourist route, when the guest picks another language,
  then the choice is stored (storage failures tolerated) and the browser loads the same route under the
  new locale's subpath. *Seam:* `core/locale.ts` (`LocaleService`) + `PageNavigation` · *Pinned by:*
  `locale.spec.ts`, `language-menu-rows.spec.ts`.
- [ ] **AC-5:** Given a first document load of `/`, when a stored choice exists it wins, else the first
  supported `navigator.languages` entry, else English; any other path is never redirected. *Seam:*
  `index.html`'s inline seed · *Pinned by:* `locale-boot.spec.ts` (drift pin against `core/locale.ts`).
- [ ] **AC-6:** Given the `sq`/`it` builds, when home, the venue map, the booking dialog, the
  confirmation, the booking view, `/for-venues` and `/help` render, then axe finds no serious
  violation and the page shows the translated copy. *Seam:* the built locale shells · *Pinned by:*
  `locales.e2e.ts`.
- [ ] **AC-7:** Dates and money display per locale while the data stays minor units (#5) and
  `Europe/Tirane` reasoning (#6). *Seam:* `shared/display-locale.ts` · *Pinned by:* `display-locale.spec.ts`.

## Non-goals

- Operator console, transactional mails, `ApiProblem` messages, legal pages (#101), German.
- Translated URL segments beyond the locale prefix; redirecting deep links by stored choice.
- `hreflang`/OG tags (#1760) and robots/sitemap (#1761), which build on `SpaLocale`.

## Risks

- **R-1:** a language cookie would make the privacy policy's "only strictly necessary cookies — a
  session cookie and a request-forgery-protection cookie" false, and legal text is a human task
  (#101) → `localStorage`, client-side first-visit redirect (ADR-0030).
- **R-2:** absolute links (`href="/help"`) leave the locale → base-relative hrefs on translated pages.
- **R-3:** three copies of `public/posters` in the jar → `scripts/prune-locale-copies.mjs` drops the
  locale copies; the app names posters and `vendor/` by absolute path.
- **R-4:** a stored choice and the redirect could loop → only the root shell redirects, only on `/`,
  and the switch writes the choice before navigating.
- **R-5:** specs asserting English → unit tests run the source locale (`@angular/localize/init`).
